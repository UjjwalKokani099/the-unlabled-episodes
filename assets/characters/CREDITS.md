# Character credits

The four characters (assets/characters/meshes/*.glb) are built by
`tools/blender/build_characters.py` from the **MakeHuman** base mesh, macro targets
(age / gender / weight / muscle / height / proportions / ethnicity) and default skeleton
weights, all released as **CC0** by the MakeHuman team (Data Collection AB, Joel Palmius,
Jonas Hauquier; original targets by Manuel Bastioni) in September 2020:
https://github.com/makehumancommunity/makehuman (fetched by tools/blender/fetch_makehuman.sh).
Clothing, garments, face painting, rig mapping and accessories are this project's own.
